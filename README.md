SmartLib
A school library tracker: every textbook mapped by number and grade, so a found book can be returned to its owner — and overdue books can be seen before they're lost.

Why
Our school's textbooks kept disappearing, and the only recovery method was asking in class chats. SmartLib gives every book a recorded location and every student a visible list of what they owe.

Features
Search by book number and grade
Report a found book
Personal debt list per student
Status
Live. Retained by the vice principal for the following year.
